# Project Overview — Blood Donation Finder

## 1. Introduction

Blood Donation Finder is a MERN-based full-stack web application designed to connect blood donors with people who need blood. It provides a centralized platform for donor discovery, blood request management, and coordination between donors and recipients.

## 2. Problem Statement

Finding suitable blood donors can be challenging, especially when blood is required urgently. Manual searching and coordination can consume valuable time.

Blood Donation Finder aims to simplify this process by enabling users to search for donors based on blood group and city, submit blood requests, manage donation availability, and track donor responses.

## 3. Project Objectives

- Connect blood donors with people requiring blood.
- Enable donor discovery based on blood group and location.
- Provide a workflow for creating and managing blood requests.
- Allow donors to update their availability and respond to requests.
- Notify users about relevant request activity.
- Provide administrators with tools for user verification and request management.

## 4. User Roles

### 4.1 Donor
- Register and log in to the platform.
- Manage donation availability.
- View matching blood requests.
- Accept or decline blood requests.

### 4.2 Recipient
- Register and log in to the platform.
- Search for donors by blood group and city.
- Create and track blood requests.
- View donor responses and notifications.

### 4.3 Administrator
- Access the administration dashboard.
- Manage donor and recipient verification.
- Review and manage blood requests.
- Monitor administrative activity logs.

## 5. Technology Stack

| Technology | Purpose |
|---|---|
| MongoDB | Data storage |
| Express.js | Backend web framework |
| React.js | Frontend user interface |
| Node.js | Server-side JavaScript runtime |
| JWT | Authentication using JSON Web Tokens |
| REST APIs | Communication between frontend and backend |

## 6. Main Modules

1. Authentication and User Management
2. Donor Management
3. Recipient and Blood Request Management
4. Donor Search and Matching
5. Notifications
6. Administration and Activity Logs

## 7. Project Scope

The project focuses on providing a web-based platform for donor discovery, blood request handling, donor availability management, notifications, and administrative oversight.

## 8. Project Status

**Under Development**

The application is undergoing testing, documentation, and refinement.

## 9. Future Scope
